# 旅游评论大模型数据标注与评测报告

## 1. 项目背景

本项目是一个小规模离线评测演示：以 40 条**模拟旅游景区评论**为对象，比较两版 Prompt 在情感分类、问题类型识别、证据提取和人工复核判断上的表现。模型输出由 AI 工具辅助生成，用于展示数据标注与评测的基本流程，不代表任何模型在真实业务中的整体表现。

## 2. 数据集说明

- 样本量：40 条中文评论。
- 数据来源：项目内人工编写的模拟数据，未采集或声称来自任何真实平台。
- 覆盖主题：服务、排队、价格、卫生、餐饮、交通、设施、景色、宣传、综合体验。
- 覆盖难点：正面、负面、中性、正负混合、反讽、多问题、信息不足。
- 当前 `gold_dataset.csv` 为**待人工逐条审核的金标准草稿**，其中 `reviewed_by_human` 均为“否”。在完成审核前，它仅是草稿参考标签，不能作为最终结论。

## 3. 标签体系

情感标签为`正面`、`中性`、`负面`。问题类型可多选，使用英文分号连接：`服务`、`排队`、`价格`、`卫生`、`餐饮`、`交通`、`设施`、`景色`、`宣传`、`其他`、`无明显问题`。证据必须来自评论原文；反讽、模糊、二手转述和正负难分的评论需标记人工复核。

## 4. Prompt V1 与 V2 的区别

| 维度 | V1 基础版 | V2 规则增强版 |
| --- | --- | --- |
| 标签解释 | 仅给出任务字段 | 给出情感和问题标签定义 |
| 多标签 | 未明确 | 要求保留所有独立主题、使用 `;` |
| 证据 | 仅要求提取 | 明确必须是连续原文，禁止补充 |
| 难例 | 无特别规则 | 规定反讽、模糊、混合情感的处理 |
| 输出 | 字段清单 | 固定 CSV 顺序与两个 Few-shot 示例 |

## 5. 评测指标定义

- **情感分类准确率**：情感预测正确的评论数 / 全部评论数。
- **问题类型完全匹配率**：一条评论预测的整组标签与草稿金标准完全一致的比例。
- **标签级 Precision**：预测出的标签中，正确标签的比例。
- **标签级 Recall**：草稿金标准标签中，被模型找出的比例。
- **标签级 F1**：Precision 与 Recall 的调和平均数。
- **证据可定位率**：预测 evidence 能作为连续片段在原评论中找到的比例。
- **输出完整率**：5 个要求字段均非空的比例。
- **need_review 准确率**：人工复核判断与草稿金标准一致的比例。

## 7. Bad Case 分析

`bad_cases.csv` 自动导出 V1 的 28 条和 V2 的 2 条字段不一致样本。以下挑选 5 个有代表性的案例：

| review_id | 版本 | 现象 | 分析 |
| --- | --- | --- | --- |
| R008 | V1 | 将反讽“真贴心”判为正面，漏掉服务标签，也未要求复核。 | 基础 Prompt 缺少反讽规则，模型按字面褒义词判断。V2 通过反讽规则修正。 |
| R010 | V1 | 只关注“主动帮忙”，判为正面，漏掉玩具陈旧。 | 正负混合时，V1 容易只选择显眼信息；V2 明确保留多主题并将整体判中性。 |
| R015 | V1 | 只提取瀑布好看，忽略垃圾桶满。 | V1 问题类型 Recall 较低，说明漏标是主要问题。 |
| R030 | V1 | 将“真有效率”理解为称赞。 | 原文实际表达“十分钟没人理”的不满，反讽需结合后半句判断。 |
| R019 | V2 | 正确识别页面说明不清，但漏标“学生票预约”对应的价格主题。 | 即使规则更详细，隐含主题映射仍可能有分歧，应由人工在金标准审核时确认。 |

## 8. Prompt 优化前后的变化

V2 的提升主要来自三个约束：一是定义多标签规则，明显减少问题漏标；二是增加反讽与混合情感规则，修正了 V1 的正负面误判；三是以固定输出格式和 Few-shot 示例稳定字段填写。本演示数据中，V2 的 Precision 已较高，改善主要体现在 Recall（60.9% 到 96.9%）。

## 9. 模型仍然存在的问题

- “学生票预约”究竟是否应归入价格，存在标签边界；V2 在 R019 中仍漏标。
- 证据可在原文定位，不等于证据覆盖了全部标签；评测可进一步增加“证据覆盖度”人工抽检。
- 当前 40 条数据较小，且输出由 AI 工具辅助生成，结果容易受样本设计和 Prompt 影响。

## 10. 人工审核的必要性

AI 可用于产出草稿、加快首轮标注，但不能同时生成参考标签并直接证明自己正确。待人工复核的金标准草稿应由项目作者逐条核对，复杂条目最好由第二位标注者抽检并记录裁决。完成审核前，当前指标只能称为“对草稿参考标签的离线对比”。

## 11. 项目局限性

本项目不接入真实平台、没有独立线上模型调用日志、没有标注者一致性统计，也没有按景区或时间分层抽样。V2 与草稿参考标签还可能存在同源生成和数据泄漏风险。因此它适合作为学习和求职展示样例，不可外推为真实旅游业务的模型效果。

## 12. 多模态扩展方向

后续可增加游客图片、短视频和语音评论：图片可标注垃圾、排队长度、设施破损；视频可评测景色真实性与导览信息；再将图文证据对齐，分别计算文本、视觉和跨模态一致性。扩展前需要取得合法数据授权，并建立更清晰的标注规范与隐私处理流程。
