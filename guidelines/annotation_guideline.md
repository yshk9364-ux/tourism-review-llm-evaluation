# 旅游评论人工标注规范（模拟项目）

> 本规范用于练习人工数据标注与模型评测。`gold_dataset.csv` 当前是待人工审核的草稿，不是已完成的人工金标准。

## 1. 情感判断

- **正面**：评论的总体态度明确满意、推荐或肯定；如“很方便”“值得”。
- **负面**：评论的总体态度明确不满、抱怨、失望或存在明显体验损害；如“太贵”“没人理”。
- **中性**：客观描述、态度不明显，或正负信息并存且难以判断整体倾向。

## 2. 问题类型与多标签

使用以下标签：`服务`、`排队`、`价格`、`卫生`、`餐饮`、`交通`、`设施`、`景色`、`宣传`、`其他`、`无明显问题`。

- 一条评论提到多个**相互独立**的主题时，全部标注，用英文分号 `;` 连接，顺序与原文出现顺序保持一致。
- 正面体验也可标主题（例如“景色很美”标为`景色`）；纯综合好评、且没有具体主题时标为`无明显问题`。
- `无明显问题`不能和其他标签同时出现。
- 无法对应既有标签、但评论与景区体验相关时使用`其他`。

## 3. 证据（evidence）

证据必须是原评论中的连续原文片段，可保留或去掉句末标点；不得总结、改写或补充评论中没有的信息。多标签或混合情感时，证据应尽量覆盖各主题。

## 4. 正负并存

先判断是否有一方明显主导：例如“景色很美，但垃圾很多”中卫生问题会影响体验，整体可标中性。若正负程度接近或难以决定，统一标中性，并保留全部主题标签。

## 5. 反讽、模糊与信息不足

- 反讽以实际不满事实为准，不按字面褒义判断。例如“真有效率，十分钟没人理”标负面，并标`need_review=是`。
- “一般”“就那样”等语义弱表达通常标中性，并标人工复核。
- 只有转述、未实际到访，或缺少评价对象时，标中性、`其他`，并人工复核。
- 天气等外部原因造成的体验受限，若无法判断是否归因于景区，标中性并人工复核。

## 6. need_review = 是

满足任一条件：反讽；正负混合但总体情感不清；语义模糊；信息不足/二手转述；外部因素导致评价不确定；标签边界存在合理分歧。其余清楚、可直接判断的评论标“否”。

## 7. 五个边界案例

| 评论片段 | 建议标注 | 分歧原因 |
| --- | --- | --- |
| “风景就那样吧” | 中性 / 景色 / 是 | 可被理解为轻微负面，也可能只是平淡描述。 |
| “大雾看不到山景” | 中性 / 景色 / 是 | 体验不好，但未必是景区可控问题。 |
| “玩具旧，但工作人员帮忙” | 中性 / 设施;服务 / 是 | 一项负面、一项正面，整体强度接近。 |
| “真贴心，晒得我很开心” | 负面 / 排队;服务 / 是 | 需识别反讽而非字面称赞。 |
| “朋友说很好玩，我没去过” | 中性 / 其他 / 是 | 没有第一手体验，不能当成可靠满意度。 |

## 8. 人工质检检查清单

- [ ] `review_id` 与原始数据一一对应，无重复、无遗漏。
- [ ] 情感只使用三种允许标签，且整体判断符合原文。
- [ ] 问题类型只使用标签体系，多标签以英文分号连接。
- [ ] `无明显问题`未与其他标签并存。
- [ ] evidence 是原文中的连续片段，可用原文检索到。
- [ ] 复杂、反讽、模糊或信息不足评论已正确标记人工复核。
- [ ] 第二位标注者抽检边界样本，记录分歧和最终裁决。
- [ ] 审核结束后，将 `reviewed_by_human` 由“否”更新为“是”，再将数据作为人工审核参考集使用。
